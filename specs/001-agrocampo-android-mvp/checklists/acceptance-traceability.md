# Trazabilidad de aceptación AgroCampo MVP

- [x] Fundación Android/Flutter, tokens, navegación y persistencia local.
- [x] Autenticación, sesión segura y aislamiento por propietario.
- [x] Parcelas, sectores, polígonos, mapas, catálogo, cultivos y rotaciones.
- [x] Labores, suelo, riego básico y borradores offline.
- [x] Motor de riego determinista configurable sin coeficientes inventados.
- [x] Sincronización outbox/inbox idempotente, estado y conflictos.
- [x] Historial y producción trazable.
- [x] Fotografías privadas, hash, deduplicación y respaldo reintentable.
- [x] Recordatorios locales, instalaciones FCM y envío servidor.
- [x] Revisión apícola con responsable descriptivo.
- [x] WeatherAPI desacoplada, cacheada y no bloqueante.
- [x] AgroIA consultiva, segura y degradable.
- [x] Exportación XLSX offline con relaciones y pendientes.
- [x] Goldens, accesibilidad, seguridad, rendimiento y resiliencia documentados.
- [ ] Firma Play Store con keystore del propietario (operación externa; no se versiona).
